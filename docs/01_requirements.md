# 01. 要件定義 — PitchNote

サッカー指導者専用のプラットフォーム。
**「AIによる指導案の提案・アドバイス」** と **「Zenn / Qiita のような知見共有ブログ」** の2本柱で構成する。

---

## 1. コンセプト

> サッカー指導者の「練習を考える時間」を減らし、「選手と向き合う時間」を増やす。

- 指導案(練習メニュー)づくりはAIが下書きを提案し、指導者が仕上げる
- 現場で得た知見は記事として共有し、指導者コミュニティ全体の質を上げる
- **指導者のみ** が参加できるクローズドな安心感(登録時に指導者情報を入力)

## 2. ターゲットユーザー

| ペルソナ | 状況 | 課題 |
|---|---|---|
| 少年団のパパコーチ | 平日は仕事、週末に指導。指導は独学 | 練習メニューの引き出しが少ない。何が正解か分からない |
| クラブチームの若手コーチ | ライセンス取得を目指している | 上位ライセンス保持者の知見に触れる機会が少ない |
| 部活動の顧問 | サッカー未経験で顧問を任された | 年代に合った練習・声かけが分からない |
| ベテラン指導者 | 20年の指導歴 | 自分の知見を残したい・共有したい場所がない |

## 3. 機能要件

### 3.1 認証・会員管理
- メールアドレス + パスワード / Google ログイン(Supabase Auth)
- 登録時に指導者プロフィールを入力(指導カテゴリ、年代、ライセンス、経験年数)
- 指導者のみのプラットフォームとして、プロフィール未入力ユーザーは閲覧のみに制限

### 3.2 AI指導案アシスタント(コア機能①)
- **指導案の生成**: 条件(年代 / 人数 / 時間 / テーマ / レベル / 用具)を入力すると、W-UP → TR1 → TR2 → GAME の流れで練習メニューを提案
- **チャット形式の相談**: 「U-10で1stタッチが大きい選手が多い。どうすれば?」のような自由相談
- **フォローアップ**: 生成された指導案に対して「もっと強度を上げて」「雨の日の体育館用に」など会話で修正
- **保存・管理**: 気に入った指導案をマイページに保存、後から編集・記事化できる

### 3.3 ブログ / 記事プラットフォーム(コア機能②)— Zenn / Qiita ライク
- Markdownエディタでの記事執筆(プレビュー付き)
- 記事のタグ付け(例: `U-12` `トレーニング理論` `保護者対応` `戦術`)
- 下書き / 公開の管理
- いいね(スキ)・ストック(ブックマーク)
- コメント
- ユーザーフォロー、フィード(新着 / トレンド / フォロー中)
- 保存した指導案を記事として公開できる(AI指導案 → 記事化の導線)

### 3.4 検索・発見
- 記事の全文検索、タグ検索
- 指導案テンプレートの検索(年代 × テーマ)

### 3.5 通知
- コメント・いいね・フォローの通知(アプリ内)

## 4. 非機能要件

| 項目 | 要件 |
|---|---|
| 表示速度 | 記事ページは SSG/ISR で高速表示 |
| セキュリティ | Supabase RLS(Row Level Security)でデータアクセス制御 |
| AIコスト | レート制限(1ユーザーあたり生成回数/日)、プロンプトキャッシュ活用 |
| 対応端末 | スマホファースト(グラウンドでの利用を想定) |
| 可用性 | Vercel + Supabase のマネージド構成 |

## 5. MVPスコープ(フェーズ1)

**やる:**
1. 認証 + 指導者プロフィール
2. AI指導案生成(条件入力 → 生成 → 保存)
3. 記事の投稿・閲覧・いいね(Markdown)
4. タグ・新着フィード

**やらない(フェーズ2以降):**
- フォロー / ストック / コメント / 通知
- トレンドアルゴリズム
- 図形描画(練習図エディタ)
- チーム管理・選手管理機能
- 有料プラン(AI利用枠の拡張など)

## 6. 収益モデル(将来構想)

- フリーミアム: AI生成 月N回まで無料、以降はサブスクリプション
- 法人プラン: クラブ・スクール単位での契約
- 有料記事 / 投げ銭(Zennモデル)
